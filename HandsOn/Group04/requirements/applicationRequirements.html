Application Requirements: BreatheMadrid

1. Application Description

BreatheMadrid is an application designed to help people in Madrid decide whether it is a good moment to carry out outdoor activities depending on the current air quality.

The user can select an area of Madrid and choose an activity such as running, cycling or walking. The application uses real-time air quality measurements together with the geographical information of the monitoring stations to show the air conditions of the selected area.

The application displays the main pollutant measurements and provides a simple recommendation based on the current air quality. Users can also explore the monitoring stations on a map and open each station to see its location and detailed measurements.

2. Target Users

The application is intended for residents and visitors in Madrid who want to check the air quality before carrying out outdoor activities, especially walking, running or cycling.

3. Data Sources

BreatheMadrid uses two complementary datasets from the Madrid Open Data portal.

  • Real-time air quality dataset: provides pollutant measurements recorded by the monitoring stations.
  • Air quality monitoring stations dataset: provides the name, address and geographical coordinates of each monitoring station.

Both datasets can be connected through the station identifier, allowing the pollutant measurements to be associated with the physical location of each monitoring station.

4. Functional Requirements

  • The user can select an area of Madrid.
  • The user can select an outdoor activity such as running, cycling or walking.
  • The application displays the current air quality information obtained from nearby monitoring stations.
  • The application displays measurements of pollutants such as NO2, PM10 and O3.
  • The application provides a simple recommendation for the selected outdoor activity based on the current air quality.
  • The user can view the air quality monitoring stations on an interactive map.
  • The user can select a monitoring station to view its location and pollutant measurements.
  • The user can filter the information displayed on the map by pollutant.

5. User Interface

The main screen shows the air quality information for the selected area and allows the user to choose an outdoor activity. The most relevant pollutant measurements are displayed together with a simple air quality indication.

A second view contains an interactive map showing the monitoring stations in Madrid. The user can filter the stations by pollutant and select one of them.

When a station is selected, the application displays a detailed view containing its name, location and the latest available pollutant measurements.

7. Expected Outcome

The expected outcome is an application that makes Madrid air quality data easier to understand and use, helping citizens make more informed decisions before carrying out outdoor activities.
