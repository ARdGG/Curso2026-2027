Application Requirements

Application description

The application will display a map of Madrid showing all BiciMAD stations. Users will be able to select a station and view information such as its name, address, station number, total number of bases and whether the station is in service.

Main functionalities

  • Display all BiciMAD stations on a map of Madrid.
  • Show the geographic location of each station.
  • Allow users to select a station on the map.
  • Display the station name and address.
  • Display the station number and total number of bases.
  • Show whether the station is currently in service.
  • Allow users to search for stations by name or address.

User interface

The main interface will include a map of Madrid with markers for each BiciMAD station. A search bar and filters will allow users to find specific stations. When a station is selected, a panel will display its detailed information.
